# Patient Health & Medication Data Analysis

## Overview
This project is part of my **Data Analysis course** and demonstrates my ability to explore, clean, and analyze real-world healthcare datasets using **Python** and **Pandas**.  

It focuses on **patient health metrics** and their **medication records**, providing insights into blood pressure trends, activity levels, and age group patterns.  

---

## Key Highlights
- ✅ **Data Cleaning & Missing Value Handling**: Properly handled missing values for blood pressure and activity status.  
- ✅ **Exploratory Data Analysis (EDA)**: Calculated average systolic & diastolic blood pressure, identified patients with high blood pressure.  
- ✅ **Activity Impact Analysis**: Compared blood pressure for active vs inactive patients.  
- ✅ **Age Group Analysis**: Categorized patients into age ranges and analyzed health metrics by group.  
- ✅ **Duplicate Management**: Detected and removed duplicate patient records for accurate analysis.  
- ✅ **Data Integration**: Merged patient health data with medication records for comprehensive insights.  
- ✅ **Visualization (Optional)**: Simple bar plots to compare blood pressure across groups.  

---

## Tools & Libraries
- Python 3.x  
- Pandas  
- Matplotlib (for optional visualizations)
